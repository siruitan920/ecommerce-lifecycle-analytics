# 召回实验方案

数据支撑与计算过程见[报告 05 召回价值测算与 A/B 实验设计](../notebooks/05_value_and_ab_test_design.ipynb)。

## 背景

- 分析发现，早期风险层（沉默 8–14 天）中历史强度前 30% 的用户 7 天自然回流率 32%，是同层后 70% 的 2.2 倍，也是最值得召回的人群（报告 04）；
- 回访风险函数显示，高强度用户沉默第 6 天以后，每多等一天自然回来的概率只再降不到 1 个百分点——**沉默第 6–8 天**是推断的触达窗口；
- 但「触达能带来多少增量」无法从自然行为里算出来，必须做实验。

## 假设

对沉默 6–8 天的高价值用户发一次「兴趣品类降价/新品」提醒，能提高 7 天回流率，且不降低 14 天人均 GMV。

## 设计

| 项 | 内容 |
|---|---|
| 实验对象 | 每天新进入「沉默第 7 天」且历史事件数为当天前 30% 的用户 |
| 随机单位 | 用户，`hash(user_id + 实验名) mod 100`，50/50 |
| 分层 | 历史强度分位（前 10% / 10–30%）× 是否下过单 |
| 实验组 | 一次 Push 或站内信，内容为该用户最常浏览品类的降价商品 |
| 对照组 | 不触达 |
| 主指标 | 7 天回流率 |
| 次指标 | 14 天人均 GMV（p99 截尾）、14 天下单率 |
| 护栏 | 推送关闭率、退订率、投诉率 |
| 排除 | 7 天内被其他活动触达过；大促前后 3 天 |
| 时长 | 不少于 14 天（覆盖两个周循环 + 14 天 GMV 观察期） |

## 样本量

基线：沉默 7 天的前 30% 用户，之后 7 天自然回来约 38%。α = 0.05（双侧），power = 0.8。
每天新进入触发条件的约 1.8 万人。

| 最小可检测提升 | 每组样本量 | 需要天数 |
|---|---|---|
| +1 个百分点 | 37,167 | 4.1 |
| +2 个百分点 | 9,335 | 1.0 |
| +3 个百分点 | 4,167 | 0.5 |

GMV 作主指标不现实：标准差是均值的 11 倍，检测 +10% 每组要 20 万人；p99 截尾后降到每组 1.6 万人，
CUPED 几乎无帮助（实验前后 GMV 相关仅 0.16）。所以 GMV 截尾后做次指标，以「不显著下降」为护栏。

## 上线前验证

在 10-31 的目标人群（59.8 万人）上做 500 次 A/A 随机分组：回流率 z 检验 p<0.05 的比例 4.8%，
截尾 GMV 的 Welch t 检验 5.8%，假阳性率符合预期。

## 分析与决策

1. SRM：两组人数比卡方检验，p < 0.001 则结果作废、排查分流；
2. 主指标：双比例 z 检验，报告差值与 95% 置信区间；分层看异质性；
3. 次指标：截尾 GMV 的 Welch t 检验 + bootstrap 置信区间；
4. ROI：实测 Δp × 增量价值（每多召回一人 14 天约 59 个价格单位，按 0.5 折扣）× 毛利率，对比真实触达成本；
5. 决策：主指标显著为正、GMV 不显著下降、护栏不恶化 → 全量；固定样本量，不中途看结果停实验。
